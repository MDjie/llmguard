## 实施范围

- 独立输出分类：政治合规、色情安全、违法有害、凭据泄漏、隐私 DLP、内部敏感数据、保险合规 7 个检测器；输出完整体、输出分块和工具结果均纳入输出策略。
- 上下文治理：结果绑定语言、司法辖区、行业、业务线、输出策略版本和法律免责声明版本；新闻、引用、教育、医学、法律与合规培训上下文采用独立风险标签，未成年人、剥削、凭据、系统提示词等平台红线不能被上下文降级。
- 保险专项：覆盖收益承诺、理赔承诺、弱化免责、弱化等待期、规避健康告知、伪造监管背书、高压营销、未做适当性、个人承诺和宣传材料冲突。
- DLP：覆盖客户身份及联系信息、保单/理赔/受益人/健康/病历/核保、银行卡/余额/收入/征信/支付、凭据、内部定价/未发布产品/规则/架构/员工数据；支持部分掩码、全量掩码、稳定不可逆令牌化、删除和阻断。
- 密钥与权限：DLP 令牌化使用独立不少于 32 字节的 HMAC 密钥；可逆令牌化使用 AES-256-GCM，并将令牌化与反令牌化权限分离；缺少令牌化密钥时保守降级为全量掩码。
- 智能干预：实现 `ALLOW / WARN / MASK / REWRITE / REQUIRE_REVIEW / SAFE_RESPONSE / BLOCK` 七级动作；响应模板具有版本、签名摘要、审批人、语言、行业、司法辖区、业务线和免责声明选择器；平台红线不可被租户模板削弱。
- 二次防护：`MASK / REWRITE / SAFE_RESPONSE` 完成后强制再次执行 DLP 与输出合规检测；复检命中红线、超时或异常统一阻断并输出固定安全答复。
- 流式防护：提交门保留完整尾部词法单元，防止凭据或敏感词跨分块拆分后提前泄漏。
- 无原文保证：公开决策、变换范围、Judge 预处理元数据、安全事件、日志和错误均不携带原始敏感值；短至 3 字符的证据预览也不会因零长度切片回拼原文。
- 可观测性：输出决策按域、动作、语言、司法辖区、行业和复检状态计量，DLP 指标按实体类型和动作计量；模板/复检失败生成不含原文的高优先级模型安全事件。
