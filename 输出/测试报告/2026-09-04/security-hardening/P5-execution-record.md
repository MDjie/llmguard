## P5-01 管理接口和权限

- 敏感词典提供草稿、校验、正反例测试、独立审批、SHADOW/CANARY 发布、编译源选择和回滚接口；词典清单包含层级、版本、状态、冲突、测试结果、签名摘要和 7 日命中趋势。
- 响应模板提供不可变版本、新建、变量白名单预览、输出复检、独立审批和上一审批版本回滚接口；模板选择器包含风险类别、动作、语言、行业、司法辖区、业务线和免责声明版本。
- /api/policy-runtime 返回 readiness、Bundle generation、编译摘要、签名公钥指纹、模型/词典/Tokenizer 摘要和应用绑定，不返回私钥、模型内部配置或原文。
- 权限拆分为 policy:read、policy:write、policy:approve、policy:publish；新写/批/发权限未自动赋予现有非系统管理员角色。平台红线和 mandatory deny 词典强制提交人与审批人分离。
- 所有新接口复用 withApiSecurity 的认证、权限、请求/查询 Schema、请求体上限、租户/应用作用域、速率限制和 append-only 审计；所有状态变更接口强制 CSRF 校验。
- 原文证据普通事件接口只返回固定隐藏标记、SHA-256 和字节数。临时查看必须提交用途，经另一名具备审批权限的人员批准，授权 15 分钟有效且仅可消费一次；消费端点仅接受带 CSRF 令牌的 POST，禁止 GET 改变授权状态；未使用的到期授权由服务端投影为 expired；证据摘要在申请、审批和消费三个阶段均重新绑定校验。
- 原文访问申请表不保存原文；申请理由和审批意见执行控制字符清理、日志脱敏和 PII 掩码。四类响应分别使用严格 Schema，意外的租户内部字段或未声明原文字段会触发响应契约失败。

## P5-02 管理页面

- 新增敏感词典治理页和响应模板治理页，使用现有 shadcn/ui 组件，并同时提供移动卡片与桌面表格布局。
- 策略发布页显示运行 generation、签名、编译、应用绑定、SHADOW/CANARY/ACTIVE 和回滚状态。
- 风险事件页默认显示去敏证据；原文访问面板显示申请、双人审批、摘要绑定、一次性查看和 60 秒自动清除。
- 控制台明确区分“治理编译源”和“实时运行策略包”：词典或模板审批不会被表述为已热更新，只有下一次签名策略包发布后才影响实时流量。

## P5-03 指标与告警

- 请求和决策指标覆盖方向、风险大类、租户桶、应用桶、语言、模态、策略版本、动作和降级结果；租户与应用仅使用 64 桶 SHA-256 派生标签。
- 探测器耗时、队列延迟、输入规模、批量、尝试次数和成本使用 Histogram/Counter；P50/P95/P99 可由 Prometheus Histogram 聚合。
- Worker backlog、任务终态、取消、资源拒绝、模板兜底、输出复检失败、SHADOW 动作差异、人工复核一致性、badcase 周期和 Bundle generation 均有独立信号。
- 策略缺失、签名失败、公钥不一致、策略摘要不一致、审计链断裂、mandatory deny 绕过和流式提交门失败进入高优先级安全告警。
- 输出域、动作、语言、司法辖区、行业和 DLP 实体类型均映射到受控枚举；自定义值统一落入 custom、OTHER 或 output.custom，原文、客户 ID 和任意客户维度不会进入 metric label。

## P5-04 灰度与回滚

- 新 Bundle 可进入 SHADOW，并记录活动/影子命中差异、动作差异和延迟差。
- CANARY 绑定在租户+应用作用域，支持 1–99% 稳定服务端哈希放量；相同 routing key 始终得到一致路由。
- 健康门禁覆盖最小样本、错误预算、错误率、P95/P99、FPR、FNR、资源拒绝、必需探测器失败和审计交付终态失败。
- 必需探测器或审计交付失败即使样本不足也立即回滚；其余阈值不足样本时保持 HOLD，不会误晋级。
- Bundle generation 是最小切换和回滚单位，词典、模板、阈值、模型及 Tokenizer 摘要随签名 Bundle 同步恢复；回滚后执行 readiness、核心烟测和审计链校验。
