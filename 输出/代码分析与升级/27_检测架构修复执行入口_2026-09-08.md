工程：PLANNED / IN_PROGRESS / OFFLINE_PASS / PASS / FAIL。
质量：NOT_RUN / INSUFFICIENT_EVIDENCE / PASS / FAIL / NOT_APPLICABLE。
部署：NOT_DEPLOYED / SHADOW / CANARY / ACTIVE / ROLLED_BACK。

每项记录：受影响文件、实际命令与退出码、失败前后对照、数据/策略/代码摘要、兼容与回滚要求、未完成项。依赖中的工程 PASS 可支持下游开发，不能代替独立质量门禁。提交、推送、生产配置和发布操作依据执行时用户授权，不从本文推导新的外部操作授权。
