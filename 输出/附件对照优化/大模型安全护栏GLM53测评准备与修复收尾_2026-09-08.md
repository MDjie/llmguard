## GLM-5.3 的实际边界

GLM 接收具有原件摘要和来源坐标的文字证据，不直接接收原始媒体。严格校验 JSON 完整性、模型身份、风险范围及 UTF-16 命中位置，禁止将元数据、跨文本视图范围或截断响应当作可靠命中。SHADOW 不改业务动作；ENFORCE 需要当前模型配置和联合提示词资格，失败进入复核。规则和其他分析分支的拒绝约束不能被一次干净的联合判定清除。

原生输入再次执行时，校验当前来源、上下文、配置、有效资格与保存的 GLM 结果，拒绝旧来源判定复用。GLM-5.3 的 thinking=disabled 配置会直接拒绝，迁移模板为 enabled + reasoning_effort=low。

[智谱官方模型文档](https://docs.bigmodel.cn/cn/guide/models/text/glm-5.3)说明该模型仅支持文本并始终启用思考。[套餐 FAQ](https://docs.bigmodel.cn/cn/coding-plan/faq)说明 Coding Plan 的工具范围与自建应用 API 使用方式。没有把“企业 Token Plan”自动解释成可以在当前护栏服务使用的 Coding 额度。

当前媒体 worker 的私有派生文本不自动外发至企业云。第一阶段隔离测评使用合成或公开且允许外发的样本；金融客户样本与原生媒体联合评测需要额外完成来源、授权和目标检测器配置。
